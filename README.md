# 情侣飞行棋 · 同机双人 MVP

成人向、原创任务、一台手机传着玩的情侣飞行棋。不含联网联机，不适合微信小程序上架。

## 怎么打开

在项目目录启动本地静态服务（推荐，手机同一 Wi‑Fi 可访问）：

```bash
cd solo-flight-chess
python -m http.server 8765
```

浏览器打开：`http://127.0.0.1:8765/`  
手机访问：`http://<电脑局域网IP>:8765/`

也可直接用浏览器打开 `index.html`（`file://`）。任务数据已写入 `tasks-data.js`，不依赖联网。

## 怎么玩

1. 勾选 18+ → 填双方昵称 → **各自选主题包**（可不同）→ 可选关闭标签 → 可加自定义牌  
2. 主题包：`甜蜜日常`（轻）/ `暧昧升温`（中）/ `干柴烈火`（重）；轮到谁就从谁的包抽牌  
3. 任务卡标明执行者：**你做 / TA做 / 一起**；可「完成 / 跳过（每人3次）/ 降级」  
4. **输赢**：先到终点（第 36 格）获胜；冲线有效；胜方抽不超过其主题包的终局任务，败方配合；终局不可跳过  
5. 自定义牌写入本机 `localStorage`，可导出 / 导入 JSON；无上传

## 文件

| 文件 | 说明 |

| `index.html` | 页面结构 |
